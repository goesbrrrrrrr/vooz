## Проверенные факты

Не пересчитывать заново — всё сверено с прогоном программ.

- **ЛР5, точное решение** задачи `y'' - 4y' + 5y = 3x`, `y(0)=1.48`, `y'(0)=3.6`:
  `y(x) = e^(2x)·(cos x + sin x) + 0.6x + 0.48`. Даёт `y(1) = 11.2900003608`.
  Порядки подтверждены: отношения погрешностей 2.002 (Эйлер) и 7.952 (РК 3.1).
- **ЛР4, тестовая задача сплайна** (пример 1 методички, сетка 0/1/2,
  f = 0/1/8, S''(0)=0, S''(2)=12): прогонка даёт ровно `c = [0, 6, 12]`,
  `max|x³ − S(x)| = 1.11e-15`.
- **Опечатка в задании ЛР4**: формула чебышёвских узлов напечатана с
  `(2i+2)` в знаменателе вместо `(2n+2)`. При `(2i+2)` все узлы сползают в
  левую половину отрезка. В коде используется каноническая формула, в
  отчёте это оговорено — не «исправлять обратно».

## Сборка отчётов

Отчёты не редактируются руками — они генерируются из скриптов, поэтому
правки вносятся в `report_src/`, а не в `.docx`.

```bash
python report_src/build_reports.py
```

Скрипт делает два прохода: собирает docx с прочерками вместо номеров
страниц, конвертирует в PDF, вынимает из вёрстки реальные номера страниц
каждого заголовка, пересобирает docx с ними и конвертирует снова. Поэтому
номера в содержании совпадают с фактической вёрсткой, а не проставлены на
глаз. Если после пересборки номера сдвинулись, делается третий проход.

Файлы:

- `vgu_report.py` — оформление под ВГУ: титульный лист, автосборка
  содержания по заголовкам, таблицы, рисунки, колонтитулы;
- `make_lab4.py`, `make_lab5.py` — содержание отчётов;
- `build_reports.py` — драйвер двухпроходной сборки.

Две грабли, на которые уже наступали — обе закрыты в коде, но легко
воспроизвести заново при переписывании:

- **Нумерованные списки.** Стиль «List Number» в шаблоне python-docx
  ссылается на один общий счётчик, поэтому второй список в документе
  продолжает нумерацию первого (выводы начинались с пункта 12). Каждому
  списку нужен свой `w:num` с `startOverride = 1` — это делает
  `_fresh_num_id()` в `vgu_report.py`.
- **Поиск страниц заголовков.** Искать в PDF по одному номеру раздела
  («1.», «2.») нельзя: он совпадает с пунктами нумерованных списков, и все
  разделы верхнего уровня получают страницу первого же списка. Искать надо
  полный текст заголовка вместе с номером.

Структура отчётов повторяет сданные ЛР1–ЛР3: титульный лист, содержание,
постановка задачи → анализ задачи → теоретические сведения → тестирование →
методика эксперимента → результаты → анализ → выводы. Times New Roman 14,
полуторный интервал, номера страниц внизу по центру.
